Open Report Designer (ORD)

A report engine for open engineering tools. You give it one typed report document; it writes the same report as PDF, HTML and Word.

  • Status: Under construction
  • Language: Rust
  • Licence: Apache 2.0

What it will be

ORD has no release yet. This is the design, from ADR 0001 and spec 0001. This page changes to "what it is" when version 0.1 is released.

  • One document, three writers. A report document (JSON, with a published schema) goes in. PDF, HTML and Word come out, with the same structure and text.
  • Pure Rust core. It opens no file and uses no network, so it can run in a command-line tool, a desktop app, Python and the browser.
  • Document control. Revision, date, prepared, checked, approved and status, with checks that a document cannot claim a status its sign-offs do not support.

Who will use it

Open Waterway Designer (OWD) is the first planned user, for its screening report.
