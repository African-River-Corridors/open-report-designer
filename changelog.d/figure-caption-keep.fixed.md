- **A run of figures breaks across pages in Word.** The Caption style keeps with the next paragraph, which a table's caption needs, as it sits above its table. A figure's caption sits below its image, so each caption kept with the next figure, and Word joined a run of figures into one block that could not break: it moved them all to the next page and left a page almost blank. A figure's caption now turns keep-with-next off, unless a map key follows it.
