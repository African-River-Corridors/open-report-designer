- **Format 0.2: the photo cover and the template values** ([spec 0002](docs/specs/0002-template-slots.md)). The engine reads `"ord": "0.1"` and `"0.2"`; a `"0.1"` document that uses a 0.2 field is refused (`ORD001`), and a `"0.1"` document renders byte for byte as before. New: a photo cover (`cover_layout: "photo"`) with `cover_image`, `cover_logos` and `cover_details`; a `footer` text and a three-column running foot with the sensitivity; tables with no caption (not numbered), with no header row, with grouped headers (`column_groups`), with inline-Markdown cells and with column widths (`width`, `table_widths: "content"`), the same in every writer; JPEG images; font assets for the PDF and HTML (`fonts`, and `ORD022` for a family nobody gives); the `text` revision form; and template values for heading ink, rule, sizes, weight and numbers, table head ink, margins, body size, the control page, the running head, page breaks and the revision prefix. The Word file's furniture is text and `PAGE`/`NUMPAGES` fields only, so it opens with no field error and can be the master.
