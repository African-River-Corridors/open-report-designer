- **A document font is found by the family it names for itself.** The PDF typesetter files a font under a shorter family: it trims width and weight words, so "Barlow Semi Condensed" became "Barlow". A template that named the full family was refused with `ORD022`, and the text of an SVG figure that named it fell back to the body font, with its letters squeezed to the drawing's text lengths. The PDF writer now also files each font of `template.fonts` under its own family (name ID 16, or else 1), and the HTML writer declares it under both names.
