- **Cover notice** (format 0.2). A document's `cover_notice` (Markdown) prints as small print at the foot of the cover page, and nowhere else: not in the running foot, not on any other page. It suits a disclaimer. On a photo cover with a filling photograph, the photograph gives up height to make room, so the cover stays one page. The same in PDF, HTML and Word. `notice` is unchanged: it still prints on the cover and in the running foot.
